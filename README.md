An AI-powered desktop application that predicts possible diseases based on user-selected symptoms using multiple Machine Learning algorithms. The application features an intuitive graphical user interface (GUI) and demonstrates the practical use of Artificial Intelligence in healthcare.

---

## 📌 Overview

This project applies Machine Learning techniques to predict possible diseases based on user-selected symptoms. It provides an intuitive desktop graphical interface and demonstrates how Artificial Intelligence can assist healthcare professionals and students in disease prediction.

## ⚙️ How It Works

The application follows a simple workflow:

1. The user selects symptoms from the graphical interface.
2. The selected symptoms are converted into numerical input.
3. The trained Machine Learning models analyze the symptoms.
4. The system predicts the most likely disease.
5. The prediction is displayed instantly through the GUI.
